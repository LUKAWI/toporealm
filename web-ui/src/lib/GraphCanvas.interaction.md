# GraphCanvas 交互契约（TopoRealm 版）

与 `D:/LUKAWI/AI_project/projects/topological-tool/web-ui/src/components/GraphCanvas.interaction.md` 同语言；
差异仅在数据语义（对象/关系无工作流状态，色彩表达 kind）。

## 交互约定

- **左键点击节点**：选中该对象，选中态 = 星芒增亮 + 标签提白 + 声呐环反馈；再次点击其他节点切换选择。
- **左键点击关系**：选中该关系（命中域为 12 单位透明加宽线）；hover 关系时提亮并显示 `source → target · kind` 标签。
- **空白点击**：清除当前选中（对象/关系一并清除），同时交还键盘焦点。
- **节点拖拽**：按住左键拖动星体，位置写入浏览器本地缓存（按图分桶）；不触发任何 Core 写入、不改变 revision。
  点击/拖拽解耦：按下无位移 = 点击（选中/展开）；首帧实际位移才钉住星体并唤醒模拟，且
  d3-drag 默认 `clickDistance(0)` 会吞掉有位移手势的后续 click——拖拽不误触点击、点击不扰动布局。
- **空白/节点中键拖动**（`button=1`，非触控）：视图连续平移。开始时画布捕获该 pointer；
  `pointerup`、`pointercancel`、`pointerleave`、`lostpointercapture`、组件卸载均结束本次平移并释放 capture。
- **滚轮**：以指针为中心缩放（0.15×–4×）；关系线宽随缩放补偿（k<1 时按 1/√k 放大）。
- **双击**：重置视图到恒等变换。
- **触控**：由 d3-zoom 手势承担（pinch 缩放/拖动）；中键处理器只响应非触控的 `button=1`。
- **键盘**：`Tab`/`Shift+Tab` 只在可见星体与容器头部条之间循环；`Enter`/`Space` 选中聚焦星体
  （折叠容器条 = 选中该类，展开容器条 = 收起）；`+`/`-` 缩放；`0` 适配全图。`Esc` 逐层消费，
  实际事件序分两相：**画布 capture 相位**先吃自己的一层（附属浮层 → 聚焦容器的展开/聚焦态），
  吃到即拦截本按键；未吃到才落进**外壳梯**（编辑器 → 选中类 → 节点/关系选中 → 浮层 → 过滤）。
  一次 Esc 只消费一层；选中类与节点/关系选中互斥，同一时刻至多一层非空，
  连按序列里「类层」与「节点层」不会连续出现。
- **搜索 Enter**（外壳）：选中并平移居中首个命中对象。
- **fit 管线**：模拟收敛（alpha ≤ 0.3）或 4s 兜底后自动取景一次；用户手动动过视角
  （滚轮/中键/缩放命令/搜索定位）或拖拽重热过布局后不再抢取景；容器尺寸变化后 180ms 防抖重新取景。
- **过滤**：搜索与 kind 过滤不匹配的星体/关系整体淡化（opacity 0.3），不隐藏、不改变数据。
- **reduced motion**：`prefers-reduced-motion: reduce` 时关闭全部装饰动画（呼吸/闪烁/声呐环/入场渐显）。

## TopoRealm 视觉语义

- 星体色彩 = 对象 kind（模块 presentation 声明色优先，未声明时确定性回退色相）；交互反馈一律用明度。
- 关系线：`directed` = 源端亮 → 目标端渐隐的不对称渐变 + 72% 处方向折角；`undirected` = 两端对称渐隐。
- 关系 hover 标签：中点显示 `label ?? kind`，tooltip 显示 `source → target · kind`。
- 视图状态（缩放、平移、坐标缓存、选择、过滤）只存在于浏览器；Core revision 不因画布操作变化。

## 语义分层渲染（D46 represent：catalog kinds 声明 `container` / `annotation`）

未声明 represent 的对象 = 普通星体，走上文全部交互；声明了的对象按下列规则分流。
represent 是**呈现声明**：模块降级（不可用）时仍生效；目录未加载（catalog 为 null）时全部按普通星体渲染。

### 容器（represent = container）

- **不画星体**：渲染为玻璃容器分区（标题 = `displayOf(object)`，左缘圆点，右缘成员计数徽章）。
- **成员**：`member_of` 关系 source 指向该容器的对象集合（任意 kind，含标注成员）。
- **实例色（1.4.2）**：容器实例色 = 按**容器 id** 的确定性哈希回退色（8 色板，`fallbackKindColor(id)`）——
  同 kind 不同实例不同色。应用于展开框描边（半透明）、头部条色点、看板行色点与选中类成员光晕；
  kind 声明色继续用于普通星体。
- **默认折叠**（容器条 + 计数徽章）。容器分两层渲染：玻璃底板层在星体之下，**头部条层
  （dot + 标题 + 计数徽章 + 键盘交互）是画布最末层**——展开态成员星体的附属角标与标题重叠时，
  头部条的点击/视觉优先；命中区只在展开态生效，折叠态不抢成员星体的点击。展开后分区玻璃底板在
  **容器局部坐标系**里包围成员星体当前位置（成员模拟坐标先减去容器星位再求包围盒，底板始终包含
  折叠条锚点，随模拟逐帧更新、随成员拖拽跟随）；成员星体本身仍是可交互星体（选择/拖拽/过滤淡化照旧）。
- **展开入口只在看板（1.4.2）**：画布折叠条点击 = 仅选中该类（`Enter`/`Space` 同）；展开态头部条/
  框体点击 = 收起（不改变选中）。展开/收起的另一通道是看板行按钮。
- **容器看板（1.4.2）**：画布右上角玻璃面板（与附属侧栏同栈互不重叠），每行 = 一个容器类：
  实例色点 + 标题 + 成员计数（过滤语义同徽章）+ 当前折叠/展开态 + 展开/收起按钮；
  数据与画布共享同一展开/选中状态。窄屏（≤768px）收纳为可展开面板（宽屏行区常开）；
  右缘详情抽屉打开时整栈平滑左移让位、关阔回位（reduced-motion 静态化）。
- **点击看板行定位（1.4.2）**：点行（非按钮区）= 选中该类并把视角平移居中到容器
  （展开态 = 框中心，折叠态 = 折叠条位置，300ms d3 transition）。
- **选中类（1.4.2）**：看板行点击或画布折叠条点击选中，独占——选新类清旧类、选类清节点选中、
  点节点/关系清类选中、空白点击全清。选中视觉：框描边实例色提亮加粗；类中成员星体加同实例色
  光晕（drop-shadow 克制脉动；`prefers-reduced-motion: reduce` 时静态）。`store.selectedContainerId`
  为浏览器本地视图状态；选中容器被删除/切图后自动失效。
- **member_of 关系不画线**：目标为声明容器的关系一律不进可见边层（成员归属已由容器分区表达）；
  但保留在力导向布局中（把成员聚拢到容器附近）。目标不是声明容器的 member_of 关系照常画线。
- **计数随过滤同步**：徽章数字 = 通过当前搜索/kind 过滤的成员数（与 `filterGraphSnapshot` 同语义，
  按 id/kind/标题匹配）；成员星体被过滤时照常淡化（0.3 透明度），容器本体不淡化（结构层）。
- 展开/收起状态、选中类、坐标缓存同为浏览器本地视图状态，不写 Core。

### 附属标注（represent = annotation）

- **不画星体**，不参与力导向模拟；按宿主判定分流：
  - **容器成员**：存在 `member_of` → 声明容器的边 = 容器成员（归属已由分区表达），不画角标、不进侧栏。
  - **恰一宿主**：参与的边（成员边除外）**恰好一条**且另一端是普通星体 → 宿主星体右上角**角标**
    （小徽章显示附属计数）。点击角标（或 `Enter`/`Space`）弹出玻璃浮层列出附属对象；点列表项 =
    `store.select` 该对象，复用 ObjectDetail 详情抽屉。浮层在 `Esc` / 空白点击 / 选中对象变化 /
    宿主星体被拖动 / 视口手势（滚轮、双击、中键平移）时收起（锚点坐标在这些场合失效）。
  - **零条或多条**（或唯一边的另一端不是普通星体）→ 右缘「附属」侧栏兜底列表（按 kind 分组，
    风格对齐 App 静态预览列表）；点列表项同样进详情。侧栏列表参与搜索/kind 过滤（附属对象可被
    搜索命中并从侧栏进详情）；无兜底对象时侧栏不渲染。
- 角标计数 = 挂靠到该宿主的标注对象总数（不随过滤缩放）；附属对象始终可经搜索 Enter（外壳）直达详情。
