# TopoRealm Join

保持只读。依次确认工作区与当前图，读取图状态、基础校验、模块状态和可发现动作；若用户指定 `--root` 或 `--graph`，非法目标直接报告，不静默回退。

用中文给出紧凑入场摘要：

- 工作区、当前图与 revision；
- 对象/关系规模及校验状态；
- 已启用、不可用或缺失的模块；
- 当前可调用的通用能力与模块动作；
- 最合适的一个后续入口：直接处理、`$toporealm-design` 或 `$toporealm-grilling`。

不得提交 `MutationPlan`、切换当前图、安装或卸载模块、执行模块动作、启动服务或同步宿主。用户随后明确要求执行时，再交给对应能力处理。
