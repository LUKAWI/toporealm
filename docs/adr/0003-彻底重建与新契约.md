# ADR-0003: 彻底重建，1.0 新契约

状态：已接受（2026-09，重建 grilling 会话 D1/D16）

## 背景

0.x 冻结了三份机器契约：图格式 `toporealm.graph/v1`（含 kinds/capabilities 信封）、模块清单 `toporealm.module/v1`（fail-closed validator、私有区守卫、20 道写路径门禁）、可恢复提交协议 v1（锁+journal）。新架构的哲学（极简 core、约束下放模块、信任前移安装时刻）与"用契约约束模块"的旧契约方向根本相反——"保持兼容地砍 core"在逻辑上不成立。项目处于 preview 阶段（Core 0.1.3、Workflow 0.1.0），真实用户面极小，打破契约的成本处于历史最低点。

## 决策

- 0.x 三契约全部废弃，不提供兼容层。
- 新架构以 `@lukawi/toporealm` **1.0.0** 发布；0.x 版本标记 deprecated。
- 提供一次性迁移 CLI：旧图 → 新格式（data/capabilities 机械合并进 payload，kind 保留）。
- Workflow 模块移植不阻塞 1.0，作为首发模块验证新协议。

## 后果

- 已有 0.x 用户图需运行迁移工具；未迁移图由旧版读取。
- Workflow 0.1.0 停止演进，语义移植到新协议后以新版本号发布。
- 旧 `.graph/` 治理图等自有资产经迁移工具保留。
