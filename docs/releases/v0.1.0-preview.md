# TopoRealm 0.1.0 Preview 发布清单

状态：发布候选准备中；尚未获得公开发布人审批准，尚未发布 npm 包、Git tag 或 GitHub Release。

## 发行边界

- 包：`@lukawi/toporealm@0.1.0`，npm dist-tag 为 `preview`。
- 包含：Core、CLI、stdio MCP、Server、Web UI、Module SDK、模块生命周期、四个基础 Skills、Codex/Claude/Pi 宿主投影。
- 不包含：`research`、`exploration`、`workflow` 或其他领域模块。
- 后续模块必须独立开发，并分别完成单模块连接测试、缺失模块降级测试和多模块组合测试。

## 发布前门禁

- [x] `npm run verify` 在本地 Windows 环境通过。
- [x] 真实 `npm pack` 产物可在临时消费者目录安装，CLI、MCP、Web 与公开库入口 smoke 通过。
- [x] tarball 不包含源码、运行图、测试 fixture 或领域模块。
- [x] Windows、macOS、Linux 的 Node.js 20 CI 使用同一套验证命令。
- [ ] 托管 CI 三系统全部通过。
- [ ] 发布候选统一独立评审与裁决通过。
- [ ] 用户明确批准公开发布。

## 发布动作（人审批准后）

1. 确认工作树、版本和发布候选证据。
2. 提交并推送待发布 commit，等待三系统 CI 通过。
3. 执行 `npm publish --tag preview --access public`。
4. 创建并推送 `v0.1.0` tag，创建 GitHub Release。
5. 从 npm registry 全新安装并复验 CLI、stdio MCP、Web 与宿主投影。
6. 记录远端 commit、tag、registry 版本和干净安装证据。

## 信任与写入边界

模块是用户主动安装的可信本地代码。模块可以提供由 Core 调用的领域操作实现，但没有图存储写权限；所有图变更只能以 `MutationPlan` 形式交给 Core 校验并提交。
