## 1.0 投影残留的手工清理（host sync 已废除，评审 B2）

1.0 的 `toporealm host sync` 在项目里生成过以下文件；1.1 起无任何进程再管理它们，按需手工删除：

- `.toporealm/hosts/`（claude-code 自包含 plugin 目录——从未接入发现体系，直接删）
- `.toporealm-sync.json`（pi 投影所有权标记）
- `.pi/extensions/toporealm/` 与 `.pi/skills/toporealm/`（1.0 项目级 pi 投影）

pi 侧的 1.1 接入方式：`pi install npm:@lukawi/toporealm`（全局）。
claude 侧：`claude plugin marketplace add LUKAWI/toporealm` → `claude plugin install toporealm`。

## 1.0 图（toporealm.graph/v2）的处置

- 1.1 daemon 只读 v3；**v2 图无自动迁移**（D25/D27）。
- 0.x v1 图仍走 `toporealm migrate`（产 v3）。
- 1.0 v2 图如需保留：手工把图目录挪到 `.toporealm/graphs/<名>/`，graph.yaml 改
  `format: toporealm.graph/v3` 并删除 `modules:` 行（参考 dogfood 自举迁移，D31）。

## 破坏性变更摘要（CHANGELOG 详见）

- 动词：`new` → `creategraph`；`version` 子命令 → `--version`；新增 `init`、`skills index`、
  `module add/rm --global`；**删除 `host sync`**。
- 布局：图存储 `graphs/` → `.toporealm/graphs/`；全局目录 `~/.toporealm`（TOPOREALM_HOME）。
- 作用域：装了就生效（全局池 ∪ 项目池，项目遮蔽全局）；modules.yaml 只剩 path 绑定职责。
- manifest：`toporealm.graph/v3`（删 modules 字段）。
- `@lukawi/toporealm-client` 的 `^1.0.0` 依赖会随 1.1.0 break（评审 B6）。
