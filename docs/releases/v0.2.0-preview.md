# TopoRealm 0.2.0 Preview

状态：本地发布候选，尚未发布。最终远端 commit、tag、CI、npm dist-tag 和 GitHub Release 证据将在人工发布门通过后补录。

## 主要变化

- `ManagedGraph` 成为唯一公开写入 seam，固定为 `read / validate / commit / undo / redo`；旧 `GraphStore` 从包根和 `/core` 公共导出移除。
- 所有受支持写入进入同一候选图校验、同机锁、recoverable journal、history segment 与最小 audit 管线。
- 模块只提供声明、只读 validator 和由 Core 调用的领域操作实现；图变更只能返回 `MutationPlan` 交给 Core 提交。
- 新增 Workspace Runtime，统一 CLI、MCP、Server、Web 的 registry、schema、validator、runtime 与 action 装配。
- Web 使用一次 revision 对齐的事实 patch；HTTP/WS 同 patch 去重，断线或 revision gap 才全量读取，并显示公开诊断、`complete:false` 与外部编辑吸收 notice。
- `package.json` 成为 Product Identity 唯一人工维护源，CLI、MCP、Codex、Claude、Pi、hooks 和 smoke 均派生 0.2.0/preview 身份。
- 0.2.x 保留旧式模块 schema 和 Workflow 0.1.0 fixture 的无损读取兼容；缺少正式 validator 时明确返回 `complete:false`。

## 兼容与迁移

- 图与模块格式仍为 `toporealm.graph/v1` 和 `toporealm.module/v1`。
- 用户级 CLI/MCP/Web 操作继续可用；TypeScript 写入调用方应改用 `createWorkspaceRuntime(...).graph` 或自行持有 `ManagedGraph`。
- 直接导入或构造 `GraphStore` 不再属于公共契约；只读旧图使用 `/core/legacy`。
- Core 0.2 不包含 Workflow、research、exploration 或其他领域模块源码。

## 候选门禁

- 全量 `npm run verify`；
- Web 类型、组件与真实浏览器/Server smoke；
- Core/CLI/MCP stdio/Server/Web 同场景矩阵；
- 多进程竞争与全部 journal 故障注入矩阵；
- npm tarball 内容与干净安装后的 Core API、CLI、MCP、Web、三宿主身份；
- 独立 agent 按 ADR 规格轴和代码惯例轴执行全图 `plumber-review`；
- 用户明确授权后才发布。
