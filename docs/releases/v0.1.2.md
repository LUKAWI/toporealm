# TopoRealm 0.1.2

这是为可信本地模块补齐专用 Web contribution 装载面的兼容性补丁。

## 变更

- Web 外壳可按模块 `ui.contribution` 的 `entry` 与 `tag` 装载隔离的自定义元素。
- Server 仅从显式绑定且可用的模块根目录托管 `/api/module-assets/<module>/<path>`，拒绝越界路径。
- `toporealm serve` 自动加载当前图可用模块的可信运行时，Web action 无需应用层手工注入。
- 模块视图的写回调统一进入 `WebGraphStore.executeAction`，与切图、其他写入共享 `switching/writing` 互斥边界。

## 验证

- Core 38 项、Web 43 项、安装包 smoke 全部通过。
- 覆盖模块资源加载、路径越界拒绝，以及 action 在途时拒绝切图和第二次写入。
