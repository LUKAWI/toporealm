- 纯领域：domain（七态/三档/三来源/三关系、流转矩阵、payload 往返）、evidence（聚合/完成门禁/代签）、

- 真缝（ModuleHost + DaemonCore + 模块 dist 直激活）：12 命令注册与目录投影（D24② forms 在案）、
  happy path 全链路、human 代签拒绝、P07 认领竞争、retry 预算、fallback 前置、DANGLING_RELATION。
- 钩子执法：CLI 直改 VETOED（流转/依赖/完成/代签/checkpoint 五类）、同状态幂等放行、
  **D24① undo/redo 豁免回归**（passed 的合法逆转可撤销可重做）、undo 后截断 redo 段。
- program dogfood：entry→exit 覆盖并行、汇合、重试、fallback、iteration、human、自验、建议裁决；
  统一提交日志（D7）>40 条。
- 打包与 skills：npm pack --ignore-scripts 自包含形状（无 dependencies、无安装脚本）；六 skills 审计。

## 四、已知边界与遗留（如实）

- **TS source 直发**：各包 `main/exports` 指向 `src/*.ts`（alpha 起的既定形态）。
  消费方需 TS 运行支持；若要 dist 直发需在发布前补各包构建链——属发布形态决策，留属主裁决。
- **web-ui 真实浏览器人工验收**：M3 起「无刷新实时同步」已有 node WS 客户端 e2e 证据；
  人工浏览器验收动作本轮未执行（无人工环境），不作为发布阻塞项记录在案。
- **workflow 模块测试的平台来源**：`file:` devDependencies 指向同级 `toporealm` monorepo；
  平台包发布 npm 后可切回 registry 版本号（后续里程碑接线）。
- **pi 宿主受管目录布局**：M5 起 `.pi/skills/` 整目录为单一所有权标记；alpha 期旧投影
  （`.pi/skills/toporealm/.toporealm-sync.json`）会在下次 `host sync` 后成为孤儿标记文件，无害。
