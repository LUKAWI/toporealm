# TopoRealm 0.1.3

这是为宿主投影补齐跨平台命令行调用能力的兼容性补丁。

## 变更

- `toporealm action execute` 新增 `base64:<base64url JSON>` 载荷格式。
- 保留原有直接 JSON 载荷，现有调用方式不受影响。
- Codex、Claude 与 Pi 等宿主包装器可以安全地转发包含引号的操作参数，避免 Windows shell 改写 JSON。

## 验证

- CLI 同时覆盖直接 JSON 与 base64url 两种 action 载荷。
- 完整 Core、CLI、MCP、Server 与 Web 验证门禁通过后发布。
