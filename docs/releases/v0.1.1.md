# TopoRealm 0.1.1

这是为独立领域模块补齐通用 CLI action 投影的兼容性补丁。

## 变更

- 新增 `toporealm action list`，返回与 MCP `action_list` 相同的 `ActionReference`。
- 新增 `toporealm action execute '<JSON>'`，按同一引用和输入调用模块运行时。
- CLI 与 MCP 均经 `ActionExecutor` 执行，模块返回的 `MutationPlan` 仍由 Core 校验 revision 后原子提交。
- 未增加任何 Workflow 专用命令或旧 `graph_*` 模块工具别名。

## 验证

- Core 全量测试、Web 测试和安装包 smoke。
- CLI action 的真实模块发现、运行时加载、MutationPlan 提交与 revision 递增。
