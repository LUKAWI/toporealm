# TopoRealm｜拓境

**以拓扑关系为核心的 agent 效率与流程管理工具：极简核心（daemon + CLI + WebUI）+ 高度自定义的双层模块系统。**

设计灵感是 [pi](https://github.com/badlogic/pi-mono)：最小的核心、体系化的扩展、以及一份人与 agent 共享的本地图数据。
